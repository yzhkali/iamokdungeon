# Honest Man Naked Base 3-View Spec v0

## Purpose

Create a modeling reference sheet before building the new Blender base body.

This is not the clothed 老实人. This is the base naked body used for future equipment layering.

## Required Character State

- 光头 / bald.
- No glasses.
- No hair.
- Bare upper body.
- Plain white triangular briefs.
- Bare feet.
- Fat chibi / Q-version proportions.
- Big round head.
- Short neck.
- Soft round belly.
- Short thick arms and legs.
- Harmless, awkward, sincere 老实人 feeling.

## Required Sheet Layout

- Exactly 3 views in one image.
- Left: front view.
- Middle: right side view.
- Right: back view.
- Same character, same height, same scale, same pose.
- Orthographic, not perspective.
- Aligned on one ground line.
- Plain neutral background.

## Required Pose

- Modeling T-pose or near T-pose.
- Standing straight.
- Feet flat and shoulder-width apart.
- Arms extended horizontally at shoulder height.
- Hands simple, palms down or neutral.
- No action pose.
