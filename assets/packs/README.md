# External Vendor Source Packs

Full third-party source packs are not stored in this git branch.

The playable prototype keeps only the runtime subset required by `prototype/3d/index.html` and the retained tool pages under:

- `prototype/3d/assets/vendor/`

## Reimport Policy

If a full source pack is needed again, download it from the original provider outside the repository, then copy only the specific runtime files needed by the prototype into `prototype/3d/assets/vendor/`.

Do not recommit complete vendor source packs under `assets/packs/vendor/`.
